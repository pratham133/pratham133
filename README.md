### ▌ About

Most AI engineers start at the model. I start at the sensor.

As an EXTC engineer, I've spent as much time soldering circuits and reading datasheets as I have tuning hyperparameters. That hardware-first instinct is why my AI work tends to ask "what does this cost to run, and where does it actually run" before "how accurate is it." I've shipped a peer-reviewed wearable on a $15 microcontroller, a 97.3%-accuracy intrusion detection API on IBM Cloud, and I'm now layering agentic AI on top of that foundation — having just completed Google's 5-Day AI Agents Intensive.

I'm currently looking for an **AI Engineer, AI/ML, or Data Analyst** internship where that hardware-to-cloud range is an asset, not a detour.
